## 3. 프로젝트 파일 내려받기

관리자(정보관리팀)로부터 받은 **`royal-ms365-mcp.zip`** 파일을 설치할 위치에 압축 해제합니다.

### 압축 해제 방법

**방법 — 탐색기**

1. `royal-ms365-mcp.zip` 파일을 설치할 위치로 복사합니다.
2. 파일을 마우스 오른쪽 버튼으로 클릭 → **"모두 압축 풀기"** 선택
3. 압축 풀기 경로를 확인합니다.  
   예: `C:\` 에서 압축을 풀면 → `C:\royal-ms365-mcp\` 폴더가 생성됩니다.
4. **"압축 풀기"** 버튼을 클릭합니다.

## 4. 패키지 설치

운영체제에 맞는 스크립트를 실행합니다.

**Windows — PowerShell**

> ⚠ **반드시 PowerShell에서 실행하세요.** 명령 프롬프트(CMD)에서는 실행되지 않습니다.  
> 시작 메뉴에서 **"Windows PowerShell"** 을 검색해 열거나, **Win + X** 단축키를 누른 후 **터미널(또는 Windows PowerShell)**을 실행하세요.

```powershell
cd {설치경로(royal-ms365-mcp)}
.\setup.ps1
```

> 실행 오류 시: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 입력 후 재시도

**Mac / Linux — 터미널**

```bash
cd {설치경로(royal-ms365-mcp)}
bash setup.sh
```

> **개발자 (HTTP 모드 포함)**: `.\setup.ps1 -Dev` 또는 `bash setup.sh --dev`

설치가 완료되면 화면에 **Claude Code MCP 등록 안내**가 자동으로 출력됩니다.

## 5. Claude Code 연결

`setup.ps1` 실행이 끝나면 화면 하단에 아래와 같은 명령어가 출력됩니다.  
`TENANT_ID`·`CLIENT_ID` 값을 채워 그대로 복사·실행하세요.  
값은 **관리자(정보관리팀)에게 문의**하여 받습니다.

```powershell
claude mcp add --scope user royal-ms365-mcp `
  "{설치경로}\.venv\Scripts\python.exe" "{설치경로}\server.py" `
  --env "MCP_SERVER_NAME=royal-ms365-mcp" `
  --env "TENANT_ID=테넌트ID" `
  --env "CLIENT_ID=클라이언트ID" `
  --env "MS365_AUTO_AUTH=false"
```

> `--scope user`는 모든 프로젝트에서 공용으로 사용하는 설정입니다.  
> 스크립트가 출력한 실제 경로(`{설치경로}` 부분이 자동으로 채워진 값)를 사용하면 편리합니다.

실행 후 **Claude Code를 완전히 종료하고 다시 실행**해야 설정이 적용됩니다.

## 6. 첫 실행 및 MS365 로그인

Claude Code를 실행한 뒤 채팅창에 입력합니다.

```
ms365 로그인해줘
```

아래와 같이 코드와 URL이 반환됩니다.

```
verification_uri: https://microsoft.com/devicelogin
user_code: XXXX-XXXX
```

1. 브라우저에서 `https://microsoft.com/devicelogin` 접속
2. 코드(`XXXX-XXXX`) 입력
3. 본인 `@iroyal.kr` 계정으로 로그인
4. **최초 로그인 시** "앱 권한 동의" 화면이 표시되면 **수락**을 클릭합니다.  
   (이메일·캘린더·Teams·SharePoint 접근 권한 동의 — 이후 로그인 시에는 표시되지 않음)

로그인 완료 후 이메일·캘린더·Teams·SharePoint 기능을 사용할 수 있습니다.

## 7. 보안 주의사항 — 토큰 캐시 파일 관리

MS365 로그인 완료 후 인증 토큰은 **로컬 파일(`token_cache.bin`)에 암호화되어 저장**됩니다.  
이 파일에는 계정 접근 권한이 담겨 있으므로 아래 사항을 반드시 준수하세요.

> **절대 Git 저장소에 커밋·공유하지 마세요.**  
> 토큰 캐시 파일이 외부에 유출되면 본인 계정(이메일·캘린더·Teams 등)이 무단으로 접근될 수 있습니다.

| 항목 | 내용 |
|------|------|
| 캐시 파일 위치 | `~/.royal-ms365-mcp/token_cache.bin` (사용자 홈 디렉터리) |
| `.gitignore` 확인 | `token_cache*` 패턴이 `.gitignore`에 포함되어 있는지 반드시 확인 |
| PC 공유·양도 시 | `ms365 로그아웃해줘` 실행 후 인계 (캐시 파일 자동 삭제됨) |
| 토큰 만료·초기화 | `ms365 로그아웃해줘` 후 `ms365 로그인해줘`로 재인증 |
| 보안 사고 발생 시 | 즉시 관리자(정보관리팀)에게 연락 |

> `ms365 로그아웃해줘` 실행 시 토큰 캐시 파일도 자동으로 삭제됩니다.

## 8. 자주 발생하는 문제

| 증상 | 해결 |
|------|------|
| `python` 명령 없음 | [python.org](https://www.python.org/)에서 Python 3.11 이상 설치 (설치 시 **"Add Python to PATH"** 체크 필수), 설치 후 PowerShell 재시작 |
| `python` 입력 시 Microsoft Store가 열림 | Python이 설치되지 않은 상태. [python.org](https://www.python.org/)에서 Python 3.11 이상 설치 (설치 시 **"Add Python to PATH"** 체크 필수), 설치 후 PowerShell 재시작 |
| `.\setup.ps1` 가 CMD에서 실행 안 됨 | 명령 프롬프트(CMD) 대신 **PowerShell**에서 실행해야 합니다. 시작 메뉴에서 "Windows PowerShell" 검색 또는 **Win + X** 단축키로 실행 |
| `.\setup.ps1` 실행 오류 (권한) | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 실행 후 재시도 |
| `.env` 파일이 안 보임 | 탐색기 → 보기 → **숨긴 항목** 체크 후 확인 |
| `.env`가 `.env.txt`로 저장됨 | 메모장 저장 시 파일 형식을 "모든 파일(\*.\*)"으로 변경 후 재저장 |
| Claude Code에 MCP 도구가 안 보임 | `claude mcp list`로 등록 확인 후 Claude Code **재시작** |
| 로그인 후 권한 오류 | 관리자에게 Azure AD 권한 동의 요청 |
| 토큰 만료 (기본 1시간, Azure AD 정책에 따라 다름) | 다시 `ms365 로그인해줘` 요청 |

### 이메일 — 분류·정리

#### 범주(카테고리) 지정

메일에 색깔 태그(범주)를 붙여서 종류별로 구분합니다.  
예: 수주완료·긴급처리·처리대기·클레임 등 업무 성격에 맞게 분류하면  
받은편지함에서 한눈에 업무 우선순위를 파악할 수 있습니다.

**범주만 지정**

```
OO건설 클레임 메일에 "긴급처리" 범주 달아줘.
```

```
오늘 받은 수주 확정 메일들에 "수주완료" 범주 달아줘.
```

```
아직 처리 안 된 발주 메일 전부 "처리대기" 범주로 표시해줘.
```

#### 팔로우업 플래그 설정

메일에 깃발 표시를 달아 "나중에 꼭 처리해야 한다"는 표시를 남깁니다.  
지금 당장 답장하기 어려운 중요 메일, 처리 결과를 확인해야 하는 메일 등에 달아두면  
나중에 플래그 있는 메일만 모아보기로 빠르게 찾을 수 있습니다.  
처리가 끝나면 플래그를 완료 상태로 바꾸거나 해제할 수 있습니다.

```
OO유통 납기 조율 메일에 팔로우업 플래그 달아줘.
```

```
아직 답장 못 한 거래처 문의 메일들에 플래그 달아줘. 오늘 중 처리해야 해.
```

```
처리 완료된 OO건설 클레임 메일 플래그 완료 처리해줘.
```

```
OO인테리어 수주 건 메일 플래그 해제해줘. 처리 끝났어.
```

#### 읽음·안읽음 처리

메일의 읽음 상태를 수동으로 변경합니다.  
**안읽음으로 되돌리기**: 확인은 했지만 나중에 다시 처리해야 할 때 안읽음으로 표시해두면  
받은편지함에서 굵게 표시되어 놓치지 않을 수 있습니다.

```
방금 확인한 OO건설 납기 문의 메일 읽음 처리해줘.
```

```
오늘 받은 생산 일정 메일 안읽음으로 다시 표시해줘. 퇴근 후 처리할 거야.
```

#### 폴더 이동·아카이브

처리 완료된 메일을 받은편지함에서 다른 폴더로 정리합니다.  
**아카이브**는 "보관" 개념으로, 삭제하지 않고 받은편지함을 깔끔하게 유지할 때 사용합니다.  
Outlook의 아카이브 폴더에 이동되며 언제든 검색으로 다시 찾을 수 있습니다.

```

```

### SharePoint·OneDrive — 파일 관리

#### 텍스트 파일 생성

SharePoint에 새 텍스트 파일(.txt)을 생성합니다.  
수주 현황·클레임 처리 결과·회의 메모 등 간단한 기록을 SharePoint에 바로 만들 때 사용합니다.

```
SharePoint 수주관리 사이트 /수주발주서/2026/ 폴더에
"20260529_수주현황.txt" 파일 만들어줘.
내용: 2026-05-29 수주 현황
      - OO인테리어: 세면기 WT-300 500개, 납기 7/15
      - OO건설: 양변기 CR-500 200개, 납기 7/20
```

```
SharePoint에 클레임 처리 결과 메모 파일 만들어줘.
파일명: 20260529_OO건설_클레임처리결과.txt
내용: 접수일: 2026-05-29, 내용: CR-500 수압불량 10개, 처리: 교환 처리 완료
```

#### 파일 업로드

내 PC에 있는 파일(PDF·Excel·Word·이미지 등)을 SharePoint 또는 OneDrive에 올립니다.  
이메일 첨부로 전달하면 버전이 분산되지만, SharePoint에 올리면 링크 하나로 최신 파일을 공유할 수 있습니다.  
4MB 이하는 즉시 업로드, 그 이상은 대용량 방식으로 자동 처리됩니다.

```
C:\수주\20260529_OO인테리어_발주서.pdf 를
SharePoint 수주관리 사이트 /수주발주서/2026/ 폴더에 올려줘.
```

```
C:\신제품\RB-7000_카탈로그.pdf 와
C:\신제품\RB-7000_사양서.xlsx 를
SharePoint 신제품 사이트 /신제품/RB-7000/ 폴더에 업로드해줘.
```

```
C:\출하\20260529_OO건설_출하명세서.pdf 를
OneDrive /출하서류/2026/ 폴더에 업로드해줘.
```

#### 파일 이름 변경

SharePoint·OneDrive에 저장된 파일의 이름을 변경합니다.  
"임시" "초안" 파일을 확정 후 정식 이름으로 바꿀 때 사용합니다.

```
SharePoint에 올라간 "발주서_임시.pdf" 파일명을
"20260529_OO인테리어_발주서_확정.pdf" 로 바꿔줘.
```

```
OneDrive에 있는 "카탈로그_v2.pdf" 를 "RB-7000_카탈로그_최종.pdf" 로 변경해줘.
```

#### 파일·폴더 이동

SharePoint·OneDrive 내에서 파일이나 폴더를 다른 위치로 옮깁니다.  
임시 폴더에 보관하던 파일을 확정 후 정식 위치로 이동할 때 사용합니다.

```
SharePoint /신제품/임시/ 폴더에 있는 RB-7000 사양서를
/신제품/RB-7000/확정/ 폴더로 이동해줘.
```

#### 파일·폴더 삭제

파일이나 폴더를 휴지통으로 이동합니다. 완전 삭제가 아니며 복구 가능합니다.

```

```

```

```

#### 공유 링크 생성

파일을 이메일 첨부 없이 링크 하나로 공유합니다.  
- **보기 전용**: 거래처·외부에 공유할 때. 상대방이 파일을 수정할 수 없습니다.  
- **편집 가능**: 사내 부서간 공동 작업 시.  
- **조직 내부만**: 링크가 외부로 유출되어도 회사 계정 없이는 열리지 않습니다.

링크 방식의 장점: SharePoint의 원본 파일을 업데이트하면 링크를 다시 보낼 필요 없이 상대방이 항상 최신 파일을 볼 수 있습니다.

```
SharePoint에 올린 RB-7000 카탈로그 공유 링크 만들어줘.
거래처에 보낼 거니까 보기 전용으로.
```

```
수주 발주서 사내 공유 링크 만들어줘. 이영업 차장이 편집도 해야 해.
```

```
OO건설 클레임 처리 결과 보고서 링크 만들어줘.
조직 내부에서만 볼 수 있게 해줘.
```
